OEM race pack dashboards are not designed for open wheel racing. So it’s heavy, the display is not visible in the daylight and drivers struggle to notice vital information. The new dashboard will use seven segment displays and LEDs to give vital information that are useful to the driver.

The Dash is designed as a CAN node which can communicate with the ECUs CAN channel. The device is based on a Teensy 3.5 micro-controller. The PCB is designed using Altium Designer.

The design will be done on driver input and as a result this will help to improve driver performance and will reduce weight.
